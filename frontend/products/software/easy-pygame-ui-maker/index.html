Interface designer

Pygame UI Designer

Arrange interface elements visually and export them as Python code for Pygame.

View on GitHub ↗Releases

What it does

  • Create buttons, inputs, text, checkboxes, images, and sliders.
  • Drag to position elements and right-click to resize.
  • Adjust properties and export UI elements to Python.

Getting started

  1. Clone or download the repository.
  2. Install the dependencies shown below and run the designer.
  3. Create and select elements, then edit their properties in the UI panel.
  4. Export your interface elements to Python code.
pip install pygame pyperclip pillow
python easy_ui_maker.py

Requirements

Python with pygame, pyperclip, and Pillow.
