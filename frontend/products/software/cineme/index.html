Dataset toolkit

Cineme

Generate aligned photorealistic and anime-style video datasets with Blender.

View on GitHub ↗Releases

What it does

  • Render the same animated scene in two visual styles.
  • Validate assets and build dataset manifests.
  • Create video previews from generated frame sequences.

Getting started

  1. Clone or download the repository and read its asset guide.
  2. Install the Python dependencies and populate the assets directory.
  3. Run the asset validator before generating a small test dataset.
  4. Follow the README’s Blender generation commands, then build a manifest and video previews.
pip install -r requirements.txt
python scripts/validate_assets.py --assets assets --report reports/asset_report.json

Requirements

Blender, Python dependencies from requirements.txt, and your own licensed characters, environments, and motion assets.

Project notes

This is a dataset generation toolkit. It does not include third-party assets or a ready-to-run video stylization model.
