Painting app

Paint App v5.9

A playful Python painting app with keyboard-driven colors, drawing modes, and rainbow effects.

View on GitHub ↗Releases

What it does

  • Switch colors and drawing modes with keyboard shortcuts.
  • Experiment with circle, square, and rainbow drawing modes.
  • Save drawings to local image slots.

Getting started

  1. Clone or download the repository, keeping the data folder beside paint.py.
  2. Install Pygame, then run paint.py from the project folder.
  3. Read the keyboard controls printed in the terminal to choose colors, modes, and save slots.
  4. To build a Windows executable, install PyInstaller and run py -m PyInstaller --clean paint.spec. The output is placed in dist/.
py -m pip install pygame
py paint.py

Requirements

Python 3 with Pygame and Tkinter. The documented PyInstaller build workflow targets Windows.

Project notes

An early project preserved for reference and personal use. The repository is archived and is no longer actively maintained.
