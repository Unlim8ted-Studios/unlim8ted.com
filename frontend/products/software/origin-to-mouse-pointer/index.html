Blender add-on

Origin to Mouse Pointer

Move an object’s origin to the mouse position with a configurable keyboard shortcut.

View on GitHub ↗Releases

What it does

  • Place object origins without manually moving the world cursor first.
  • Choose a shortcut in the add-on preferences.
  • Use U as the default shortcut when available.

Getting started

  1. Open GitHub Releases and download Origin-To-Mouse-Pointer.zip.
  2. In Blender, open Edit → Preferences → Add-ons → Install from Disk.
  3. Select the ZIP, enable the add-on, and configure its shortcut.
  4. Select an object, move your mouse to the desired position, and press the shortcut.

Requirements

Blender. Check the repository for compatibility with your Blender version.
