Local network chat

ChatApp

Chat over a local network through a Pygame interface with animated weather effects.

View on GitHub ↗Releases

What it does

  • Separate server and client applications.
  • Local server discovery and custom usernames.
  • Recent message history for newly connected users.

Getting started

  1. Clone or download the repository and install its dependencies.
  2. Start python server.py on the host computer.
  3. Run python client.py on each client computer.
  4. Select a discovered server or enter its IP address, then choose a username.
pip install pygame pywin32
python server.py
# On each client computer:
python client.py

Requirements

Python 3, Pygame, and pywin32. Primarily built for Windows; clients connect over the local network on port 9999.

Project notes

A small experimental chat app for trusted networks. It has no encryption, authentication, accounts, or persistent message storage.
