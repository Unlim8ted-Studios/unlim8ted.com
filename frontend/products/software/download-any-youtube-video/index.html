Media utility

YouTube Video Downloader

A Python desktop interface for downloading video, audio, and available captions.

View on GitHub ↗Releases

What it does

  • Download video with audio or choose audio only.
  • Request captions in a specified language.
  • Choose an output folder from the graphical interface.

Getting started

  1. Clone or download the repository and install its requirements.
  2. Run main.py to open the interface.
  3. Enter a video URL, choose your output folder and caption options, then select Download.
pip install -r requirements.txt
python main.py

Requirements

Python 3, Tkinter, pytube, and youtube-transcript-api. Dependencies are listed in requirements.txt.

Project notes

Restricted videos and unavailable captions may not work. Upstream YouTube changes can affect this tool.
