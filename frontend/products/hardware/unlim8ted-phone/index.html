CM4 handheld project

Unlim8ted Phone.

Unlim8ted Phone is a handheld device in development, based on the Raspberry Pi Compute Module 4. The project includes the hardware assembly, a 3D-printed enclosure, and a local software interface.

Project overview

Hardware, enclosure, and software.

The current design combines off-the-shelf components with a custom enclosure and software. Development files include 3D models, source code, and build documentation.

The 3D viewer displays the enclosure parts individually. The software preview below provides access to the interface in a browser.

01 / Hardware

Hardware configuration.

CM4 + display + power.

The build uses a CM4, Waveshare carrier and display hardware, a LiPo power board, and a battery.

02 / Enclosure

Enclosure design.

The enclosure consists of a main shell, removable covers, and internal mounts for the CM4, battery, and power board. Additional parts provide space for the camera and USB-C connector.

03 / Software

Device software.

Local interface.

The device software uses a local kiosk interface and a Python backend for its modules.

04 / Earlier designs

Archived PCB designs.

Previous custom board designs are available in the repository for reference. The current hardware assembly uses off-the-shelf modules.
